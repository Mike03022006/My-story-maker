# 🔊 Guía Rápida - Instalar Voces en Celular

## 📱 ANDROID (5 minutos)

### **Paso 1: Abrir Configuración**
```
Configuración (⚙️) 
  → Idioma y entrada 
  → Salida de texto a voz
```

### **Paso 2: Verificar Motor**
- Debe decir: **"Motor de síntesis de voz de Google"**
- Si no está, descárgalo de Google Play Store

### **Paso 3: Instalar Voz en Español**
```
Toca ⚙️ junto al motor de Google
  → Instalar datos de voz
  → Busca "Español (España)" o "Español (Estados Unidos)"
  → Descargar (espera 1-2 minutos)
```

### **Paso 4: Configurar**
```
Vuelve a "Salida de texto a voz"
  → Motor predeterminado: Google
  → Idioma: Español
  → Velocidad: Normal
```

### **Paso 5: Probar**
- Toca **"Escuchar un ejemplo"**
- Deberías escuchar una voz en español
- Si funciona, **reinicia el celular**

## 🍎 iOS (10 minutos)

### **Paso 1: Abrir Ajustes**
```
Ajustes (⚙️)
  → Accesibilidad
  → Contenido hablado
  → Voces
```

### **Paso 2: Descargar Voz en Español**
```
Toca "Español"
  → Selecciona una voz:
     • Mónica (España) - Femenina ⭐ Recomendada
     • Jorge (España) - Masculina
     • Paulina (México) - Femenina
     • Juan (México) - Masculina
  → Espera a que se descargue (2-5 minutos)
```

### **Paso 3: Activar Leer Pantalla**
```
Vuelve a "Contenido hablado"
  → Activa "Leer pantalla"
  → Activa "Leer selección"
```

### **Paso 4: Probar**
- Abre Notas
- Escribe "Hola, esta es una prueba"
- Selecciona el texto
- Toca "Hablar"
- Deberías escuchar la voz en español

### **Paso 5: Reiniciar**
- **Reinicia el iPhone** (importante)

## ⚠️ SI NO FUNCIONA

### **Android**:
1. ✅ Verifica que el **volumen multimedia** esté alto (no el de llamada)
2. ✅ Actualiza **Google Text-to-Speech** en Play Store
3. ✅ **Reinicia el celular**
4. ✅ Vuelve a descargar la voz en español

### **iOS**:
1. ✅ Verifica que la voz esté **completamente descargada** (sin ícono de nube)
2. ✅ Ve a Ajustes → Accesibilidad → Contenido hablado → Voces
3. ✅ Elimina y vuelve a descargar la voz
4. ✅ **Reinicia el iPhone**

## 📞 AYUDA RÁPIDA

### **¿Qué celular tienes?**

**Android**:
- Samsung → Usa Google TTS (no Samsung TTS)
- Xiaomi → Usa Google TTS (no Xiaomi TTS)
- Huawei → Usa Google TTS
- Otros → Usa Google TTS

**iOS**:
- iPhone/iPad → Usa voces de Apple (Mónica o Paulina)

### **¿Qué navegador usas?**

**Android**:
- ✅ Chrome (recomendado)
- ✅ Firefox
- ⚠️ Otros navegadores pueden no funcionar

**iOS**:
- ✅ Safari (único que funciona bien)
- ❌ Chrome en iOS no soporta TTS

---

## 💡 TIPS

1. **Descarga las voces con WiFi** (son grandes, 50-200 MB)
2. **Reinicia el celular después de instalar** (importante)
3. **Usa el volumen multimedia, no el de llamada**
4. **Mantén el navegador actualizado**
5. **Si usas iOS, solo Safari funciona bien**
